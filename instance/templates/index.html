PERSONAL FILE HOST
==================
{% set host = url_for("fhost", _external=True, _scheme="https").rstrip("/") %}
This is a personal instance of 0x0, not a public upload service.
Yes, uploads require a login. That's intentional: this page is public
so the owner can use it as a README, and visitors know what to expect.

Got a file link on IRC? Just open it. Downloads need no account.
Uploading files, fetching remote URLs, and managing files require the
owner's HTTP Basic Auth credentials. Public registration is not available.

OWNER'S QUICK REFERENCE
-----------------------
Replace USERNAME with your login. curl will prompt for the password.

Upload a local file:
    curl -u USERNAME -F 'file=@yourfile.png' {{ host }}/

Fetch a remote file and host a copy:
    curl -u USERNAME -F 'url=https://example.com/image.jpg' {{ host }}/

Add a random secret to the returned link:
    curl -u USERNAME -F 'file=@yourfile.png' -F 'secret=' {{ host }}/
The link is still public: anyone who has it can download the file.

Expire an upload after 24 hours:
    curl -u USERNAME -F 'file=@yourfile.png' -F 'expires=24' {{ host }}/
The expires field also accepts a Unix timestamp in milliseconds.

Download a shared file without authentication:
    curl -O {{ host }}/abc.txt

Save upload response headers to keep the management token:
    curl -u USERNAME -D headers.txt -F 'file=@yourfile.png' {{ host }}/
X-Token is returned for a new or expired file. Keep that token private.

Delete a file (requires both your login and its management token):
    curl -u USERNAME -F 'token=TOKEN' -F 'delete=' {{ host }}/abc.txt

Change its expiration to three hours from now:
    curl -u USERNAME -F 'token=TOKEN' -F 'expires=3' {{ host }}/abc.txt
